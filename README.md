# taxi-fleet-bot — MVP бота для управления таксопарком

Telegram-бот: владелец ведёт парк, водители платят аренду, передают пробег,
репортят неисправности. Напоминания — автоматом.

## Что работает (проверено `demo_run.py`)

- Роли: owner / admin / driver — разные меню
- Автомобили: добавление, статусы `rented/free/repair`, закрепление за водителем
- Платежи: водитель шлёт сумму + фото чека → владелец подтверждает/отклоняет
- Долг: аренда за прошедшие дни платежа − подтверждённые оплаты
- Пробег: запись с фото одометра, защита от отката, расчёт «до ТО N км»
- Неисправности: репорт водителя с фото → владельцу
- Напоминания (`reminders_due`): день платежа, ТО за 1000 км, страховка за 14 дней,
  долги — планировщик APScheduler (cron 09:00 + еженедельный запрос пробега)
- Статистика: авто по статусам, подтверждённый доход, общий долг, открытые issue

## Стек

Python 3.11+, aiogram 3.x, SQLAlchemy, APScheduler.
Демо — SQLite (`sqlite:///fleet.db`), прод — PostgreSQL: только смена `FLEET_DB_URL`.

## Запуск

```bash
pip install -r requirements.txt
FLEET_BOT_TOKEN=xxx FLEET_OWNER_CHAT_ID=123 python bot.py
```

## Демонстрация логики без Telegram

```bash
python demo_run.py   # полный сценарий: парк → платежи → пробег → напоминания → статистика
```
